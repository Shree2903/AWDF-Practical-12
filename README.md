# AWDF Practical 12 — CI Pipeline

This practical implements Continuous Integration (CI) for the Task Manager API using GitHub Actions.

## Features
- Automated backend dependency installation.
- Automated API tests using Jest and Supertest.
- CI workflow triggered whenever changes are pushed to the `main` branch.
- Verification of successful builds and detection of failing tests.

## Technologies Used
- Node.js
- Express.js
- Jest
- Supertest
- GitHub Actions
